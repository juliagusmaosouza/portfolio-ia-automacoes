# Ferramentas internas e automações com IA

Ferramentas que desenvolvi em Google Apps Script, HTML, CSS e JavaScript com apoio de IA generativa (Claude/ChatGPT) para programação, como estagiária de Planejamento Estratégico, para as etapas do ciclo estratégico de uma diretoria financeira. Os dados reais foram substituídos por placeholders.

| Projeto | Problema | O que faz | Escala |
|---|---|---|---|
| [Roadmap do ciclo de iniciativas](./roadmap-iniciativas/) | Falta de visão consolidada das iniciativas do ciclo estratégico | Dashboard com filtros, previsão de entregas por mês, gráfico de Gantt por time e % de avanço de cada iniciativa | [N] iniciativas |
| [Automação de SG&A](./automacao-sga/) | Atualização manual da base de SG&A com relatórios de mobilidade e viagens recebidos por e-mail | Lê e-mails por palavra-chave no assunto, baixa ou abre os relatórios anexados por link, filtra as colunas e alimenta a planilha de SG&A. Feita para outra diretoria (Crédito, Cobrança e Fraude) | [N] relatórios/mês |

## Ferramentas

Google Apps Script, JavaScript, HTML, CSS, Claude

## Como usei IA

Não tenho formação em programação. Eu descrevia o problema e o fluxo de negócio, pedia o código por partes, testava nas planilhas e ajustava os prompts até funcionar.
